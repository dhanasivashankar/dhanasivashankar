## 🗡️ About Me

I'm a Computer Science student and aspiring **Java Backend Developer** with a strong foundation in object-oriented programming, data structures & algorithms, and relational databases. My primary focus is building reliable, well-structured backend systems using **Java and Spring Boot**, backed by clean REST API design and solid database fundamentals in **SQL**.

I approach every project with attention to code quality, and every algorithmic problem as an opportunity to sharpen my analytical thinking.

I'm currently seeking opportunities where I can contribute as a backend developer, continue learning from experienced engineers, and grow into a well-rounded software professional.
